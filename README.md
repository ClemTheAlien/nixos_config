# Welcome to ClemTheAlien's NixOS Dotfiles 
Make sure to ```sudo nixos-rebuild switch --flake .nixos_config[INSERT_HOST]``` or use the built in ```world_update``` or ```boot_update``` to update your config. 
To install the system read the HOWTO.md guide in the docs folder. **When in doubt read the HOWTO.md.**

![Screenshot](./assets/screenshot1.png)

> **Remeber to start the script on a fresh NixOS install so the builtins can work (```world_update```,```boot_update```)**
